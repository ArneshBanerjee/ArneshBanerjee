## Projects
- [GPT-2 in Assembly](https://github.com/ArneshBanerjee/gpt2.s): GPT-2 small in hand-written ARM64 assembly, with no C and no libc calls. It reads the original Hugging Face files, runs at about 100 tokens per second on one M1 core, and matches PyTorch token for token. Write-up on [my blog](https://arneshbanerjee.dev/blog/gpt2-in-assembly.html).
- [Kimi K3 for All](https://github.com/ArneshBanerjee/Kimi-K3-for-All): Moonshot released Kimi K3 with inference code only. I rebuilt the training pipeline from scratch, fixed the four places where the released code cannot train, and trained a 1.27B test model with it. Weights on [Hugging Face](https://huggingface.co/ArneshBanerjee/Kimi-K3-for-All), write-up on [my blog](https://arneshbanerjee.dev/blog/kimi-k3-for-all.html).
